Lantern Twins is an original spot-the-difference game. Two pictures hang side by side in a lantern-lit frame — a harbour at dusk, a foxglove garden, a night market — and ten tiny changes hide between them: a gull that flew off, a sail in another colour, a frog that hopped away, a lantern burning green instead of amber. Find all ten before the clock runs out, then hunt the next scene.

A find earns a gold ring, a chime and a sparkle, and combos build your score. A wrong click costs five seconds. Hints are limited — three per scene, with a cooldown — and each one lights a pulsing ring around a difference you have not found yet. The keyboard plays too: arrows or WASD move the crosshair, Space clicks, H hints, P pauses, M mutes, R restarts the scene.

No libraries, no build step, no network requests — just static files under `game/` that open in desktop Chrome and play, with original art drawn in code and sound synthesised live with the Web Audio API.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `game/` with any static server.
